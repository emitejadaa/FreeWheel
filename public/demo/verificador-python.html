1 Levantar el verificador en tu máquina — una sola vez

Esta página no pasa por el backend NestJS: le habla directo a python-verifier/server.py. No hace falta tener el backend levantado, ni cuenta, ni Cloudinary, ni base de datos.

  1. Instalar el binario de tesseract con español (es del sistema operativo, no viene con pip): 
    # Ubuntu/Debian
sudo apt install tesseract-ocr tesseract-ocr-spa
# macOS
brew install tesseract tesseract-lang
# Arch
sudo pacman -S tesseract tesseract-data-spa tesseract-data-eng
  2. Instalar las dependencias de Python en un entorno propio: 
    cd python-verifier
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
  3. Levantar el servidor con CORS prendido (sin eso el navegador no lo puede llamar): 
    DOCVERIFY_ALLOW_ANONYMOUS=true DOCVERIFY_CORS_ORIGIN='*' .venv/bin/python server.py
# escuchando en :8000 · tesseract: tesseract 5.3.4 · cors: *
    Con token, que es como va a correr en el server de verdad: DOCVERIFY_TOKEN=loquesea DOCVERIFY_CORS_ORIGIN='*' .venv/bin/python server.py y el mismo valor arriba, en el campo del token.
  4. Probar /health con el botón de arriba. Si dice tesseract: NO ESTÁ, el OCR no corre y todas las fotos van a fallar: falta el paso 1.
Con DOCVERIFY_ALLOW_ANONYMOUS=true el verificador queda abierto a cualquiera que llegue al puerto, y con DOCVERIFY_CORS_ORIGIN='*', a cualquier página que abras en el navegador. Es solo para localhost: en un servidor expuesto va con token y con los orígenes listados uno por uno.
2 Fotos — las mismas que subiría la persona

Arrastrá una foto a su casillero o tocá para elegirla. Las fotos no salen de tu máquina: van del navegador al Python de tu localhost, en base64, y el server las borra apenas termina.

sin fotos

Reducir achica el pedido, pero le saca definición al PDF417 y al MRZ: si una foto anda sin reducir y falla reducida, es eso. El tope del server es 32 MB por pedido.

Leer las dos fotos de un documento tarda 30–60 s en una máquina normal: el análisis endereza la tarjeta, corre OCR por zonas y decodifica el código. La primera vez suele tardar más.
3 Datos de la cuenta — opcional, para cruzarlos contra lo leído

El verificador Python no compara nada: solo lee y devuelve. Estos campos son para que esta página haga el cruce y te muestre si el documento alcanzaría. Vacíos, el cruce igual corre entre protocolos (código vs. MRZ vs. OCR).
